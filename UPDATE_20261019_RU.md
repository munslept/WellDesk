# WellDesk: обновление интерфейса Windows от 19.10.2026

Это обновлённые исходники, не собранный EXE. Основа — прежний WellDesk на RustDesk
1.5.0. Android-комплект 1.4.9 в этом обновлении не изменён.

## Изменения

1. SVG/PNG/JPG/ICO больше не исключаются из Git. Все исходные рисунки панели
подключения присутствуют в архиве. В Windows workflow добавлена проверка
обязательных UI-ресурсов перед компиляцией. Это устраняет найденную причину,
по которой в сборку могли попадать синие кнопки без изображений.

2. ico2.png преобразован в значок Windows с размерами 16–256 и PNG приложения.
ico5.png используется как логотип и надпись окна распаковки. Обновлены иконки
основного EXE, portable EXE и трея.

3. IP и серверный Key сохранены. Встроен запрошенный постоянный пароль удалённого
доступа через штатный механизм preset password. Режим приёма — по паролю, без
подтверждения каждого сеанса на принимающей стороне. Пользователь может задать
свой постоянный пароль: он имеет приоритет над встроенным. Старые сохранённые
настройки режима доступа также имеют приоритет над новыми значениями по умолчанию.
Для первого теста используйте чистый профиль WellDesk либо проверьте режимы
пароля/подтверждения в настройках безопасности.

Встроенный общий пароль известен всем, кто получил эту сборку: это не уникальный
секрет конкретного ПК. Распространяйте сборку только среди согласившихся клиентов
или своих устройств. Программа не скрывается, разрешения Windows не обходятся.

4. На Windows вместо плоских меток отображается дерево «Папки»:
- папки и подпапки со своими названиями, включая пустые;
- сохранение веток раскрытия на этом ПК между запусками;
- добавление ID в папку через её меню;
- перемещение компьютера через меню справа от его строки;
- подключение нажатием на компьютер;
- отображение компьютеров без папки отдельной веткой;
- выбор папки фильтрует карточки справа с учётом подпапок.

Существующие метки становятся папками. Иерархия хранится в именах вида
«Офис/Этаж 2/Бухгалтерия» поверх существующего API меток. Не используйте / или \
в самом имени папки. Полный путь ограничен 128 символами и 12 уровнями.
Перемещение из дерева назначает компьютеру выбранную папку вместо прежних меток.
Обычные заметки к компьютерам сохранены — заменена именно панель «Метки».

5. Изменения папок и состава отправляются на сервер сразу. Каждые 10 минут клиент
тихо перечитывает список адресных книг и текущую книгу. Новые недавние подключения
по умолчанию добавляются в адресную книгу; старое пользовательское отключение
этой опции сохраняется. Наличие ID в адресной книге не предоставляет дополнительных
прав доступа: подключение по-прежнему проходит штатную проверку пароля.

## Обновление вашего Windows-репозитория

1. Закройте старую локальную папку архива, если она открыта в редакторе.
2. В существующем Git checkout сохраните свои изменения отдельным коммитом.
3. Скопируйте содержимое папки WellDesk из ZIP поверх файлов checkout.
   Не удаляйте .git и не переносите Android 1.4.9 поверх этого проекта.
4. В PowerShell в корне checkout выполните:

```powershell
python tools/check-welldesk-assets.py
git add .
git commit -m "Restore artwork and add WellDesk folder tree"
git push origin main
```

Проверьте `git status` до commit. Если раньше не отслеживали upstream-workflow,
не добавляйте их все: после `git add .` выполните `git reset -- .github/workflows`,
затем добавьте только:

```powershell
git add .github/workflows/welldesk-windows.yml .github/workflows/welldesk-bridge.yml .github/workflows/third-party-RustDeskTempTopMostWindow.yml
```

5. GitHub → Actions → Build WellDesk Windows → Run workflow → main.
6. В шаге Build rustdesk сначала выполняется Flutter analyze нового виджета;
   ошибка анализа остановит сборку до упаковки. После успешного запуска скачайте
   Artifacts → WellDesk-Windows-x64. Готовый EXE положите на сайт как WellDesk.exe.

## Сервер и синхронизация

Данные сохраняются штатными маршрутами /api/ab/tag/* и /api/ab/peer/* текущей
адресной книги. Полная серверная часть в этом ZIP отсутствует и не изменялась.
Актуальный код вашего API в этой сессии недоступен, поэтому исчезновение папок
из-за серверного ответа, разрешений или базы ещё не диагностировано.

Если папка после создания снова исчезает или другой оператор её не видит,
нужны актуальный архив API (без .env, паролей, токенов и приватных ключей)
и журнал `docker compose logs --tail=100 api` из папки сервера. Названия и состав
папок синхронизируются только между аккаунтами с доступом к той же адресной книге.
Локальное раскрытие веток отдельно на каждом рабочем месте.

## Проверки и пределы проверки

- Присланные изображения просмотрены; созданы настоящие многослойные ICO.
- Скрипт проверяет наличие 39 необходимых UI-ресурсов.
- Синтаксис трёх изменённых Dart-файлов проверен парсером Dart.
- Сверены доступные методы AbModel, Peer, bind и путь штатного подключения.
- В CI добавлен Flutter analyze нового виджета.
- Полная Windows-сборка, Flutter UI, подключение по preset password и реальная
  синхронизация с вашим API здесь не запускались. Нельзя считать это уже проверенным
  установщиком до успешной сборки и теста на двух ПК.

## Изменённые пути выполнения

- .gitignore и Windows workflow: включение ресурсов, проверки перед сборкой.
- libs/hbb_common/src/config.rs: штатные начальные настройки доступа и синхронизации.
- flutter/lib/models/ab_model.dart: периодическое чтение адресной книги.
- flutter/lib/common/widgets/address_book.dart: Windows-панель дерева вместо меток;
  мобильная панель меток сохраняет прежнюю реализацию.
- Новый welldesk_folder_tree.dart: операции папок через существующие методы модели.
- Файлы ресурсов приложения: только предоставленные значки/логотипы.

Сеть, протокол сеансов, права доступа адресной книги, серверный ключ и механизмы
аутентификации не заменялись.
